# 추가 영상 5개 설명란 검증

검증일: 2026-10-22 (Asia/Seoul). 공식 YouTube `search.list(part=snippet,type=video,q=셰프 맛집,maxResults=5)`로 검색한 뒤 각 영상에 `videos.list(part=snippet)`를 호출했다. 자막, 영상 파일, 외부 지도 모음 페이지는 수집하지 않았다.

5개 모두 직접적인 주소가 없었다. 이 표본에서 ‘설명란에서 식당+주소를 항상 자동 추출할 수 있다’는 가정은 성립하지 않는다. 주소 없는 이름 후보를 검색할 수는 있지만, 장소가 실제 영상의 식당인지 자동 확정하지 않는다. 링크 목적지를 추가로 분석하는 기능은 이번 구현에 포함하지 않았다.

기존 [윤남노포 EP.47](https://www.youtube.com/watch?v=RMTJPFKRbEk)은 ‘상호 줄 → 주소 줄’이 두 번 등장한다. 이 영상의 **두 후보가 별도 Mention으로 추출**되는 회귀 테스트를 추가했다. 추가 표본의 실제 설명란 5개는 `backend/src/test/resources/video-cases.json`에 고정하여, 이름 후보 1개·주소 없음·나머지 4개 후보 없음의 동작을 재현한다. 주소가 있는 추가 영상 표본은 확보하지 않았으므로 다양한 주소 형식 전반의 정확도가 검증됐다고 주장하지 않는다.

원본 응답은 Git 제외 경로 `results/additional_videos.json`에 저장했다. `python validate_additional_videos.py`로 다시 검색할 수 있지만 검색 결과는 시간에 따라 달라질 수 있다. 고정 표본의 추출 동작은 Java 단위 테스트로 재현한다.

첫 기능은 다음 원칙을 따른다.

- 설명란 원문, 추출된 줄 번호와 근거를 함께 보관한다.
- 주소를 추측하지 않고 없는 값은 공란으로 남긴다.
- 자동 추출이 누락된 경우 관리자가 원문 근거를 붙여 수동 후보를 추가한다.
- 채널명과 셰프를 동일시하지 않는다. 승인 시 관리자가 셰프와 추천 근거를 지정한다.
- 후보 검색과 공개 승인을 분리한다. 후보가 검색돼도 승인 전에는 공개 지도에 나타나지 않는다.
